# Week 6 Starter: Functions, Objects and Arrays

## Files

| File                     | Purpose                                                 |
| ------------------------ | ------------------------------------------------------- |
| `index.html`             | Page that loads the JavaScript. Open this in Chrome.    |
| `starter.js`             | Teaching file with TODOs for live coding and exercises. |
| `solution.js`            | Finished version.                                       |
| `assignment-template.js` | Blank template for the take-home assignment.            |

## Setup in VS Code

1. Unzip the folder and open it in VS Code (File > Open Folder).
2. Install the **Live Server** extension (optional but useful).
3. Right-click `index.html` and choose **Open with Live Server**, or just double-click `index.html` to open it in Chrome.
4. Press `F12` in the browser and open the **Console** tab to see output.

## Teaching flow

1. Work through `starter.js` top to bottom, live-coding each TODO.
2. Uncomment the test lines as each exercise is completed.
3. To show the finished version, change `starter.js` to `solution.js` in `index.html`.
4. For the take-home assignment, give students `assignment-template.js` to rename to `assignment.js`.
